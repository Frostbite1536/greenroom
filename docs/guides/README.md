# Greenroom guides

Short, plain-language walkthroughs for the people who actually run an event. No setup
knowledge required — start signed in.

| Guide | For you if… |
| --- | --- |
| [Event admin](event-admin.md) | you run the call for speakers and build the programme |
| [Evaluator](evaluator.md) | you have been asked to score proposals |
| [Speaker](speaker.md) | you submitted a talk, or your talk was accepted |

All three use the same demo event, **Forward 2026** (12–14 May 2026), and its three
sign-in personas: **Maya Chen** (event admin), **Ravi Patel** (evaluator), and
**Sofia Marques** (speaker). On the demo, `/login` signs you in as any of them with one
click — no password.

Developer-facing documents live one level up: [`../ARCHITECTURE.md`](../ARCHITECTURE.md),
[`../LIFECYCLE.md`](../LIFECYCLE.md), [`../API.md`](../API.md).
