# Greenroom Program Manager Roadmap

## Phase 0 — Foundation (Architect)
- Lock Abstract vs Session domain boundary, form/evaluation/schedule contracts, shell, and verification commands.
- Exit: Prisma validates, client generates, typecheck/build pass, and database push succeeds once credentials exist.

## Phase 1 — Golden path (parallel)
- Backend: public form submission, evaluation scoring, accept/convert, and schedule conflict services.
- Frontend: form builder/public renderer, evaluation queue, and agenda workspace.
- Ops: speaker profile/task portal, communications, `.ics`, and onboarding visibility.
- Exit: one abstract travels from draft through published schedule.

## Phase 2 — Integration and fidelity
- Accelevents mock, mapped CSV/JSON import, realistic deterministic seed data, public schedule/speaker embeds.
- Add populated, loading, empty, error, and responsive states to judged screens.

## Phase 3 — Demo hardening
- Deployment, authorized idempotent demo reset, review checkpoints, accessibility/performance audit, and clean-environment rehearsal.

## Explicit exclusions
- CRM, marketing automation, payments, multi-language support, AI evaluation, production OAuth, and speculative enterprise permissions.
