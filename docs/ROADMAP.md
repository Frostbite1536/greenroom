# Sprint Roadmap

## Phase 0 — Reconnaissance
- Reveal target and identify golden path, key screens, data, and non-goals.

## Phase 1 — Foundation
- Lock minimal shared contracts and schema.
- Establish runnable shell, env example, test/typecheck/build commands.

## Phase 2 — Golden path
- Implement one end-to-end user workflow with realistic seeded or fixture data.

## Phase 3 — Fidelity and secondary features
- Add the highest-value target screens and interactions without destabilizing the golden path.

## Phase 4 — Demo hardening
- Auth/demo reset, error/loading states, responsive polish, deployment, review, and rehearsal.

## Explicit exclusions until justified
- Production-grade billing, OAuth, realtime infrastructure, elaborate permissions, and speculative abstractions.
