 3. Agent Communication Protocol
 Having AI agents continuously "chat with each other" across branches can lead to consensus drift or wasted token budgets. Instead, use a file-based, asynchronous sync

 Pr-Based Merging: Worktrees push short-lived feature branches, and the central Architect agent merges them sequentially to keep tests passing.

 Why This Tweak Works
 Zero Merge Conflicts: By isolating by folder structure (e.g., app/api/* vs. app/(dashboard)/*), agents never touch the same files simultaneously.

 Deterministic Context: Each sub-agent gets a hyper-focused task without being distracted by what the other agents are doing.

 Continuous Working State: main is always runnable and deployable from hour 2 onward.
