Create or update your status file under `$SPRINT_COORDINATION_DIR/status/` with:
- UTC/local timestamp and branch
- current commit SHA
- 5-bullet summary
- files/interfaces changed
- checks run and results
- assumptions and risks
- shared-file/schema requests
- exact recommended next action

Keep it factual and concise. Coordination state is advisory and may be stale; commits and code are authoritative.
